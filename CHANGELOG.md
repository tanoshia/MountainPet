# MountainPet - Changelog

## v0.3.3 - Minimum Follow Distance
- Added configurable minimum follower distance setting
- Pet maintains a minimum gap from the player instead of bunching up

## v0.3.0 - Overlap Nudge
- Pet gets nudged slightly when overlapping or positioned behind the player
- Prevents visual clutter when standing still

## v0.2.2 - 16 Directions
- Axolotl now supports 16 swim directions (N, NNE, NE, NEE, E, SEE, SE, SSE, S, SSW, SW, SWW, W, NWW, NW, NNW)
- 9 unique west-side direction sprites with FlipX mirroring for east-side
- Added randomize color toggle

## v0.1.0 - Initial Release
- Basic pet follower using Celeste's native Leader/Follower system
- Custom axolotl sprite with idle and swim animations
- 16 color variants
- Works on all levels without map edits
- In-game settings menu (enable/disable, pet type, color)
